 About The Project

DigitalPro is a professional landing page designed for a digital marketing agency. The website presents the agency's services, portfolio section, creative team, company statistics, and contact information in a clean and modern layout.

 Features

- Modern and responsive user interface.
- Hero section introducing the agency.
- Integrated digital marketing services.
- Our Work section for showcasing projects.
- Company statistics and achievements.
- Creative team profiles.
- Contact form section.
- Contact information and social media links.
- Modern gradient colors and clean design.

 Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

 Website Sections

1. Home: Introduction to DigitalPro.
2. Services Search: Engine Optimization, Social Media Marketing, and Website Design & Development.
3. Our Work: Portfolio and selected campaigns.
4. Our Team :Introducing the creative team.
5. Contact Us: Contact form and company information.

 Getting Started

To run the project locally:

1. Clone the repository:

   bash
   git clone https://github.com/Reemaeyad/Digital-Pro-Website.git
   

2. Open the project folder:

   bash
   cd Digital-Pro-Website
   

3. Open `index.html` in your browser.
